# Employee Management and Task Summary System

## Project Overview

This is a Python project that manages employee and task information
using JSON files.

The project demonstrates Python fundamentals, including file handling,
JSON processing, functions, exception handling, searching, filtering,
data validation, and Git version control.

## Features

- Read employee and task data from a JSON file.
- Validate employee and task information.
- Search employees by name.
- Filter employees by department and role.
- Search tasks by title.
- Filter tasks by status and priority.
- Handle missing files and invalid JSON data.
- Generate employee and task summary reports.
- Export summary reports to a JSON file.

## Technologies Used

- Python
- JSON
- Git
- GitHub (optional, for remote repository hosting)
